# 🚀 Claude Code 中文汉化 - 快速开始

**预计时间：5 分钟**

> 即使你从未接触过命令行，也能轻松完成！

## 📦 安装前检查

### 1. 确保已安装 Claude Code

```bash
# 检查 Claude Code 是否安装
which claude

# 或者查看 npm 全局包
npm list -g @anthropic-ai/claude-code
```

如果���示 `not found` 或 `not installed`，先运行：

```bash
# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version
```

### 2. 确保有网络连接

首次运行需要下载依赖，需要 **网络连接**。

## 🎯 3 步快速安装

### 步骤 1️⃣：下载汉化脚本

打开终端，运行：

```bash
# 创建保存目录
mkdir -p ~/claude-汉化备份

# 进入目录
cd ~/claude-汉化备份

# 克隆项目
git clone https://github.com/qq845200/claude1688.git

# 进入项目
cd claude1688
```

或者直接下载 ZIP 文件：
- 访问 https://github.com/qq845200/claude1688/archive/refs/heads/main.zip
- 解压到 `~/claude-汉化备份/`

### 步骤 2️⃣：运行恢复脚本

```bash
# 确保在项目目录
cd ~/claude-汉化备份/claude1688

# 运行汉化脚本
bash 恢复汉化.sh
```

## ✨ 验证安装成功

启动 Claude Code 后，检查以下几点：

1. **界面文本是否为中文？**
   - 欢迎信息："欢迎回来！" ✅
   - 命令列表：中文命令描述 ✅

2. **斜杠命令是否中文？**
   - `/help` → 显示「显示帮助信息和可用命令」✅
   - `/config` → 显示「打开配置面板」✅

3. **工具提示是否中文？**
   - 执行 Bash 命令后显示中文解释 ✅
   - Read/Edit/Write 工具显示中文提示 ✅

4. **状态栏是否中文？**
   - 下方显示「Claude 监控: ...」✅

## 🔄 升级后怎么办？

Claude Code 升级后，汉化可能会被还原。有两种方式重新应用：

### 方式 1：自动恢复（推荐）

启动 Claude Code，自动钩子会检测并重新汉化：

```bash
claude
# 后台自动检查和重汉化
```

### 方式 2：手动恢复

```bash
# 进入项目目录
cd ~/claude-汉化备份/claude1688

# 再次运行脚本
bash 恢复汉化.sh

# 重启 Claude Code
claude
```

## 🆘 常见问题速查

| 问题 | 解决方案 |
|------|----------|
| **命令找不到** | 确保已装 Node.js，运行 `npm install -g @anthropic-ai/claude-code` |
| **权限不足** | 运行 `chmod +x 恢复汉化.sh` |
| **脚本出错** | 查看完整错误信息，参考 [常见问题 FAQ](常见问题FAQ.md) |
| **汉化没有生效** | 确保已保存所有文件，重启终端和 Claude Code |
| **升级后变回英文** | 再次运行 `bash 恢复汉化.sh` 或等待自动钩子 |

更多问题？查看 [完整 FAQ](常见问题FAQ.md)
