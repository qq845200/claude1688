## 🔍 环境检查

### 检查 1: 操作系统

**macOS 用户：**
```bash
# 查看系统版本
softwareupdate -l | head -10

# 或者点击菜单 > 关于本机
```

**Linux 用户：**
```bash
# 查看系统版本
lsb_release -a
```

**Windows 用户：**
- 需要使用 **WSL 2**（Windows Subsystem for Linux）
- 请参考 [Windows WSL 安装指南](#windows-wsl-安装)

### 检查 2: Node.js 环境

```bash
# 检查 Node.js 版本（需要 16+）
node --version

# 检查 npm 版本（需要 8+）
npm --version
```

**如果提示命令找不到？**

前往 [nodejs.org](https://nodejs.org/) 下载安装。选择 **LTS 版本**。

安装后重新打开终端，再次运行上面的命令验证。

### 检查 3: Claude Code 安装

```bash
# 检查是否已安装 Claude Code
which claude

# 应该显示类似：
# /usr/local/bin/claude
```

**如果提示 `not found`？**

运行以下命令安装：
```bash
npm install -g @anthropic-ai/claude-code

# 然后验证
claude --version
```

### 检查 4: Git（可选但推荐）

```bash
# 检查 Git 是否安装
git --version

# 应该显示：
# git version 2.x.x
```

**如果没有安装？**
- macOS: 安装 Xcode Command Line Tools: `xcode-select --install`
- Linux: `sudo apt install git` (Debian/Ubuntu) 或 `sudo yum install git` (RedHat)

## 📝 详细安装步骤

### 步骤 1: 创建保存目录

```bash
# 创建目录
mkdir -p ~/claude-汉化备份

# 进入目录
cd ~/claude-汉化备份

# 验证（应该看到 claude-汉化备份）
pwd
```

### 步骤 2: 下载项目

**方案 A：使用 Git（推荐）**

```bash
# 克隆仓库
git clone https://github.com/qq845200/claude1688.git

# 进入项目
cd claude1688

# 验证
ls -la
# 应该看到 恢复汉化.sh 等文件
```

**方案 B：下载 ZIP（无 Git）**

1. 打开浏览器：https://github.com/qq845200/claude1688/archive/refs/heads/main.zip
2. 下载 `claude1688-main.zip`
3. 解压到 `~/claude-汉化备份/`
4. 进入目录：

```bash
cd ~/claude-汉化备份/claude1688-main
```

### 步骤 3: 赋予执行权限

```bash
# 进入项目目录（如果还未进入）
cd ~/claude-汉化备份/claude1688

# 赋予脚本执行权限
chmod +x 恢复汉化.sh

# 验证
ls -l 恢复汉化.sh
# 应该看到 x 标记，如：-rwxr-xr-x
```

### 步骤 4: 运行汉化脚本

```bash
# 确保在项目目录
cd ~/claude-汉化备份/claude1688

# 运行脚本
bash 恢复汉化.sh

# 脚本会自动：
# 1. 检测 Claude Code 安装位置
# 2. 创建备份
# 3. 应用汉化
# 4. 配置钩子
# 5. 显示成功信息
```

**脚本运行时间**：2-5 分钟（取决于 Claude Code 版本大小）

### 步骤 5: 重启 Claude Code

```bash
# 如果 Claude Code 正在运行，先关闭
# 按 Ctrl+C（可能需要按多次）

# 稍等 2-3 秒

# 重新启动
claude
```

## 🎓 逐行命令解释

### mkdir -p ~/claude-汉化备份

```
mkdir   = make directory（创建目录）
-p      = 父目录不存在时自动创建
~       = 用户主目录（如 /Users/你的用户名）
claude-汉化备份 = 目录名称（中文名）
```

**作用**：创建 `~/claude-汉化备份` 目录，-p 参数表示如果父目录不存在会自动创建。

### cd ~/claude-汉化备份

```
cd  = change directory（切换目录）
```

**作用**：把当前工作目录切换到 `~/claude-汉化备份`。之后的命令都在这个目录执行。

### pwd

```
pwd = print working directory（显示当前目录）
```

**作用**：显示当前工作目录的完整路径。用来验证 `cd` 是否成功。

### git clone https://github.com/qq845200/claude1688.git

```
git clone  = 克隆仓库
URL        = 仓库网址
```

**作用**：从 GitHub 下载整个项目到本地。会创建 `claude1688` 子目录。

### chmod +x 恢复汉化.sh

```
chmod   = change mode（改变权限）
+x      = 增加执行权限
文件名  = 要改权限的文件
```

**作用**：使脚本文件可执行。没有执行权限的脚本无法运行。

### bash 恢复汉化.sh

```
bash       = shell 解释器
脚本文件   = 要执行的脚本
```

**作用**：用 bash 解释器运行脚本。这是实际应用汉化的地方。

## 🆘 问题排查

### 问题 1: "command not found: git"

**原因**：未安装 Git

**解决**：
- macOS: `xcode-select --install`
- Ubuntu: `sudo apt install git`
- 或使用方案 B（下载 ZIP）

### 问题 2: "Permission denied" 或 "permission denied: ./恢复汉化.sh"

**原因**：脚本没有执行权限

**解决**：
```bash
chmod +x 恢复汉化.sh
bash 恢复汉化.sh
```

### 问题 3: "npm: command not found"

**原因**：未安装 Node.js

**解决**：
1. 下载 Node.js LTS：https://nodejs.org/
2. 按照安装向导完成安装
3. 重新打开终端
4. 验证：`node --version`

### 问题 4: "Cannot find Claude Code binary"

**原因**：Claude Code 未安装或路径不正确

**解决**：
```bash
# 检查安装
npm list -g @anthropic-ai/claude-code

# 如未安装，运行：
npm install -g @anthropic-ai/claude-code

# 验证
claude --version
```

### 问题 5: 脚本运行失败，显示错误信息

**解决步骤**：

1. **记录完整错误信息**

```bash
# 再次运行脚本，记录所有输出
bash 恢复汉化.sh 2>&1 | tee install.log

# 查看日志
cat install.log
```

2. **检查日志文件**

```bash
# 查看汉化过程日志
tail -50 /tmp/claude-localize.log
```

3. **提交 Issue**

在 GitHub 提交 Issue，附上完整错误日志：
https://github.com/qq845200/claude1688/issues

### 问题 6: 汉化后启动 Claude Code 依然显示英文

**原因**：可能是缓存问题

**解决**：

```bash
# 方案 1: 完全关闭并重启
# Ctrl+C 关闭当前 Claude Code
# 等待 5 秒
claude

# 方案 2: 清除缓存
rm -rf ~/.claude/cache/*
claude

# 方案 3: 重新应用汉化
bash 恢复汉化.sh
claude
```

## 🔙 卸载和还原

### 还原为原始英文版本

```bash
# 查看备份文件
ls -la ~/.claude/localize/backups/

# 复制备份文件覆盖当前版本
# （以 macOS arm64 为例）
cp ~/.claude/localize/backups/claude-2.1.148.bak.exe \
   /opt/homebrew/lib/node_modules/@anthropic-ai/claude-code/bin/claude.exe

# 重启 Claude Code
claude
```

### 完全卸载汉化工具

```bash
# 删除汉化文件
rm -rf ~/.claude/localize
rm -rf ~/.claude/hooks
rm -rf ~/.claude/monitor

# 删除下载的项目（可选）
rm -rf ~/claude-汉化备份

# 还原 Claude Code 为原始版本
npm install -g @anthropic-ai/claude-code@latest

# 验证
claude --version
```
